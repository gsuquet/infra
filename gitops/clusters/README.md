# Clusters (GitOps)

One folder per cluster, `gitops/clusters/<name>/`: `cluster.yaml` (edited by hand) and `rendered/<component>/` (generated by `mise run manifests:render`, never edited by hand).
How rendered manifests reach the cluster: [Rendered manifests](../../docs/concepts/rendered-manifests.md); fields: [GitOps files](../../docs/reference/gitops-files.md).
